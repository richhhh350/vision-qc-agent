# v1.0.0：CPU 视觉质检闭环原型

版本日期：2026-10-13。定位：可运行、可复现的研究作品，尚未通过产线自动放行验收。

## 此版本可以做什么

训练正常图像记忆库，输出异常分数、热力图及候选框；用独立校准数据形成预测集合并进行放行 / 报警 / 人工复核路由；记录标签修改历史；对复核池执行三种主动学习选样；由反馈生成候选模型并用新独立样本重新校准。

附带中文看板、FastAPI、Windows 启停脚本、ONNX 导出、实验脚本、Docker 配置和自动化测试。默认 CPU 模型是本项目的手工特征 patch memory，不是论文版 PatchCore。

## 已有证据

| 项目 | 结果 |
|---|---:|
| KolektorSDD2 完整官方测试集 | 1,004 张，110 张缺陷 |
| 主检测 Image AUROC | 0.928229 |
| 主检测 Pixel AUROC | 0.922754（96×96） |
| 主检测近似 AUPRO@0.30 | 0.812767（96×96） |
| 主检测 CPU 推理 p50 / p95 | 2.40 / 3.65 ms |
| 独立路由验收漏检 | 1 / 73 个缺陷 |
| 验收漏检率 95% 单侧上界 | 6.33%，未达到 1% |
| 实际服务自动放行 | 关闭 |
| 守门后测试集人工复核率 | 80.58% |
| 本地测试 | 18 passed |
| NumPy / PyTorch / ONNX 数值一致性 | 通过 |

推理时延不包含图像解码、HTTP 和存储。低分辨率定位指标不能当作官方原分辨率成绩。关闭放行带来的零放行漏检，不代表实现了低人力成本的 99% 召回。

数值快照在 [results/v1](../../results/v1/README.md)，详细边界在 [验证结果](../验证结果.md)。

## 下载后运行

```powershell
git clone https://github.com/richhhh350/vision-qc-agent.git
cd vision-qc-agent
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1
powershell -ExecutionPolicy Bypass -File scripts/start.ps1
```

访问 <http://127.0.0.1:8501>。初次安装需要下载 Python 依赖，setup 会生成合成演示数据与模型。运行真实数据版本需按 [公开数据集评测](../公开数据集评测.md) 自行下载、导入、训练。

Git 中只包含代码、文档、看板截图与汇总指标。不包含原始数据集、训练权重、用户上传图、SQLite、虚拟环境或凭据。使用的第三方数据与依赖遵循各自许可，见 [第三方说明](../第三方说明.md)。
