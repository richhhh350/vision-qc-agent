# v2.0.0：CPU 深度检测与可审查反馈研究版

2026-10-14 本地交付记录。此文件不代表 GitHub Release 已发布。

v1 使用手工 patch 特征，缺陷标签无法训练检测器。v2 接入正式 Anomalib PatchCore 和 CPU 预算 EfficientAD，并让人工像素掩膜训练小型 U-Net；检测、校准、人工队列、候选训练与回滚在同一服务中运行。

新增等比例/重叠切片及原图热力图恢复、dev/acceptance 隔离、完整策略哈希、证书有效期、单次新证据使用登记、后台训练与取消、掩膜修订绑定、ONNX 对照、模型注册表及真实池三种子学习实验。

本机 39 项测试通过，依赖一致性检查通过，2.0.0 wheel 已构建。安装包位于本地 `dist/vision_qc_agent-2.0.0-py3-none-any.whl`，仓库命令见 [使用与复现](../v2使用与复现.md)。本机完整演示使用 `runs/v2-review-balanced`。

研究目标未全部达到：KSDD2 切片 PatchCore Image AUROC 0.9418；开发集选中的等比例服务配置 Image AUROC 0.9343、原图 Pixel AUROC 约 0.9899。1% 漏检风险、复核率降低和主动学习省标注的目标不能声称已经通过；自动放行仍关闭，二级只提供人工建议。所有结果、原始负结果和边界见 [验证报告](../v2验证报告.md)。

Windows 依赖版本快照已保存。新 Linux 深度 CI 尚未推送运行；Docker 本机不可用，未验证构建。MVTec/VisA 全类别评测、完整 EfficientAD 论文训练、特征空间漂移、VLM 和生产采样仍属于后续范围。

模型权重、原始数据和人工图片仅保存在本地；公共结果文件包含数值、样本 ID、策略轨迹和哈希，不含个人绝对路径。回滚使用注册表命令并重启服务，v1 入口保持可用。
