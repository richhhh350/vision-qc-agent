# v1 评测快照

这些 JSON 是 2026-10-13 本地真实实验的汇总结果副本，随 v1 源码发布。不含原始图像、数据集、权重、逐图本机路径或复核数据库。

| 文件 | 含义 |
|---|---|
| [ksdd2-main.json](ksdd2-main.json) | 单类检测主基准：2,085 正常训练，完整 1,004 张官方测试 |
| [ksdd2-routing.json](ksdd2-routing.json) | 另一套训练划分下的路由实验；通过守门后的放行比例为零 |
| [ksdd2-onnx.json](ksdd2-onnx.json) | 路由模型的 ONNX 数值一致性及固定张量 CPU 计时 |
| [environment.json](environment.json) | 原实验实际依赖版本，不是跨平台锁文件 |

主检测与路由模型使用不同数量的训练正常图，不能拼成同一个模型的成绩。`ksdd2-routing.json` 中的 `release_gate.validation` 是关闭放行前的风险验收；顶层指标是实际关闭放行后的测试结果。

主报告中的 manifest SHA-256 指向原实验 CSV 字节；其中路径的机器差异可能导致重新生成的文件哈希不同。未来 v2 将增加基于图像内容与 split 的可移植划分指纹。

原数据来源、原压缩包 SHA-256、定位分辨率和计时边界见 [完整验证报告](../../docs/验证结果.md)。运行步骤见 [公开数据集评测](../../docs/公开数据集评测.md)。合成实验成绩没有混入这些真实数据快照。
