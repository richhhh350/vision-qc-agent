# 源码、数据与第三方资源

本仓库用于公开展示和研究复现。当前尚未为原创源码指定开源许可证；公开可见不等同于授予任意再分发或商业使用许可。需要开放授权时，由仓库所有者另行选择许可证。

仓库不重新分发工业数据集、预训练权重或人工上传图片。`data/`、`runs/`、本地环境与数据库均排除在版本控制外。`results/v1/` 仅保存本项目计算的汇总数值；看板截图不含工业原图。

| 资源 | 来源及处理 |
|---|---|
| KolektorSDD2 | [ViCoS 官方页面](https://www.vicos.si/resources/kolektorsdd2/)，页面声明 CC BY-NC-SA 4.0；使用前核对下载版本 |
| MVTec AD / LOCO | [MVTec AD](https://www.mvtec.com/research-teaching/datasets/mvtec-ad)、[LOCO](https://www.mvtec.com/research-teaching/datasets/mvtec-loco-ad)，按原发布者许可使用 |
| VisA | [AWS Open Data](https://registry.opendata.aws/visa/)，许可与 MVTec 不同，单独核对 |
| BTAD | [Anomalib 数据入口](https://github.com/open-edge-platform/anomalib/blob/main/src/anomalib/data/datamodules/image/btech.py)，核对原始包说明 |
| 深度模型与权重 | [Anomalib](https://github.com/open-edge-platform/anomalib) 及其权重提供者的许可分别适用；v1 未打包这些权重 |
| Python 依赖 | 通过包管理器安装，包列表见 `pyproject.toml`；遵循各包自身许可 |

KolektorSDD2 论文引用：Jakob Božič, Domen Tabernik, Danijel Skočaj. *Mixed supervision for surface-defect detection: from weakly to fully supervised learning*. Computers in Industry, 2021.
