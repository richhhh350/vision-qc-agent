## 独立路由实验

保持同一完整官方测试集，全部校准/验收只从官方训练部分划分：1,459 张正常训练；prob_fit 244 张；calibration 318 张（110 缺陷）；validation 283 张（73 缺陷）。

固定路由在验收集上把 1/73 缺陷错误放行：点估计 1.37%，95% 单侧上界 **6.33%**，未达到 1% 目标。故服务实际关闭自动放行。

| 上线守门后的官方测试集指标 | 结果 |
|---|---:|
| Image AUROC | 0.923307 |
| 自动放行比例 | **0%** |
| 人工复核比例 | **80.58%** |
| 自动报警比例 | 19.42% |
| 自动报警误报率 | 11.63% |
| ECE | 0.06410 |

“实际自动放行零漏检”来自关闭放行，不能宣传为实现了低人力成本的 99% 召回。未经风险守门的预测集合在测试缺陷上的覆盖率约 98.18%；分布假设、有限样本和类别子群都需要进一步研究。

结果保存在 `runs/ksdd2-routing/metrics-test.json`。这是当前真实水平，也给下一阶段留下明确优化目标：改进模型与成像特征，扩大独立验收样本量，再降低人工复核率。

## ONNX 与系统验证

KolektorSDD2 路由模型已导出 ONNX，ONNX checker 通过，输出与对应 PyTorch 图以及原 NumPy 分数通过一致性校验。示例热力图最大绝对误差约 `2.74e-6`。

固定预处理张量、CPU 单线程、batch=1、预热 10 次后测量 50 次：PyTorch p50 1.717 ms，ONNX Runtime p50 1.394 ms；p95 分别为 2.075 / 2.578 ms。因此本次不能笼统声称 ONNX 的所有延迟指标都更快。该计时不包含缩放、路由和 HTTP。

最终完整测试：**18 passed**。有一条 Starlette 关于测试客户端未来迁移的弃用提示，不影响本次结果。覆盖正常校准集不能保证放行、p 值离散分辨率、并列分数、空预测集合、精确风险上界、泄漏检测、官方测试集完整性、重复文件记录、幂等上传、认证、标注冲突和历史、候选训练及新数据重新校准。测试使用临时数据，不把真实测试图用于训练。

已实际通过服务接口检查、看板渲染和一次浏览器标注回流。依赖检查无损坏要求。Docker 本机不可用，未执行构建；深度 PatchCore/EfficientAD、GPU、VLM 和监督分割对照未在此环境训练或验证。

## 合成流程检查

1,304 张程序生成图像用于离线可运行性；160 张独立测试图像中的 Image AUROC=1.0、复核率=3.125%。这些不是工业数据结果。80 张缺陷零漏检的上界仍为 3.675%，不能拿这个实验宣称工业漏检率≤1%。

三种选样策略、路由曲线及六种扰动实验已输出到 `runs/demo/experiments/seed-42/`。主动学习曲线没有强行制造“越标越好”的效果；它们仅验证选样与模型更新路径，不证明真实缺陷适应能力。
