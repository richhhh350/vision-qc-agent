# 公开数据集作为主评测

主评测使用公开数据的原始测试集；合成数据仅检查工程流程。当前 CPU 模型用于建立真实基线，不应把轻量特征的结果当成论文 PatchCore 成绩。

## 数据集安排

| 数据集 | 项目中的作用 | 读取入口 | 需要特别披露 |
|---|---|---|---|
| MVTec AD | 核心异常检测基准，逐类别和宏平均 | `--kind mvtec` | 15 类；仅正常训练，不能拿 test 缺陷做路由校准 |
| VisA | 多实例、跨产品泛化对照 | `--kind visa` | 按官方 `split_csv/1cls.csv`，12 类 |
| BTAD | 较小工业产品补充基准 | `--kind btad` | 类别为 01/02/03，读取 ok/ko 目录 |
| KolektorSDD2 | 首个真实 CPU 验证与带训练缺陷的路由研究 | `--kind ksdd2` | 主检测只用正常训练图；路由可使用训练缺陷 |
| MVTec LOCO | 逻辑异常压力测试 | `--kind loco` | 合并区域掩膜仅用于辅助 AUROC；正式定位需要官方 sPRO |

本次不是“所有论文模型、五个数据集全部完成”的实验。入口覆盖上述格式，已实际跑过的数据与指标以验证报告为准；其他入口通过格式测试后仍需真实包验证。

## 官方 train/test 协议

```powershell
python scripts/import_dataset.py --kind mvtec --root D:/datasets/mvtec --category bottle --output data/bottle-official.csv
python scripts/benchmark_public.py --manifest data/bottle-official.csv --output runs/bottle-main
```

默认 `--protocol official` 不拆官方训练正常图，保留完整测试集。训练中的异常图不进入正常记忆库，放入 pool 且在主报告中披露数量。主评测不拟合路由阈值、不报告自动放行风险保证。

主报告包含完整测试图像 AUROC、当前分辨率下的 pixel AUROC / 近似 AUPRO、实际样本数量、排除训练缺陷数、运行环境、预处理方式和 manifest SHA-256。默认 CPU 特征为 96×96，小缺陷缩放后可能消失；该定位指标不与原分辨率论文结果直接等同。

逐类别循环执行后，再对类别 AUROC 做宏平均；不应简单混合不同类别分数计算一个总体 AUROC。

## KolektorSDD2：从下载到报告

```powershell
.\.venv\Scripts\python.exe scripts/download_ksdd2.py
.\.venv\Scripts\python.exe scripts/import_dataset.py --kind ksdd2 --root data/public/ksdd2/dataset --category ksdd2 --output data/ksdd2-official.csv
.\.venv\Scripts\python.exe scripts/benchmark_public.py --manifest data/ksdd2-official.csv --output runs/ksdd2-main
```

若原包解压后多了一层目录，`--root` 指向实际含 train/test 的目录。下载支持分段续传，来源与本地计算的校验值保存在 `data/public/ksdd2/source.json`。未提供发布者校验值时，不把本地 SHA-256 描述为“已与官方校验值比对”。

## 独立路由协议

```powershell
.\.venv\Scripts\python.exe scripts/import_dataset.py --kind ksdd2 --root data/public/ksdd2/dataset --category ksdd2 --protocol routing --output data/ksdd2-routing.csv
.\.venv\Scripts\python.exe -m vision_qc.cli train --manifest data/ksdd2-routing.csv --output runs/ksdd2-routing
.\.venv\Scripts\python.exe -m vision_qc.cli evaluate --run runs/ksdd2-routing --manifest data/ksdd2-routing.csv
```

官方测试集保持不变。所有校准/验收/概率拟合来自官方训练部分。训练缺陷不足以支持 1% 风险验收时，关闭自动放行是正确结果，不能放宽条件后仍声称达到原目标。

MVTec/VisA/BTAD 的常见单类协议没有训练缺陷，此时可报告检测排序性能与正常误报控制；要研究严格漏检风险，应补充独立缺陷校准数据或用具有训练缺陷的数据集。
